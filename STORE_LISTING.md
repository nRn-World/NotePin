## English

### Short description (≤132 characters)

```
Pin sticky notes to any webpage. Anchor to elements, stay private, work offline.
```

### Detailed description

```
NotePin lets you pin floating sticky notes directly onto any webpage — right where you need them.

How to create a note
On any page, hold right-click for 1 second. NotePin opens a menu so you can add a sticky note without fighting the normal browser context menu.

What you get
- Smart sticky notes that stay on the page you created them on
- Drag to move, resize from the corner, and click to bring a note to the front
- Auto-save while you type
- Saved Notes dashboard to search, open, and manage notes across sites
- Export / import JSON backups
- Optional browser sync when available; otherwise data stays local
- English and Swedish UI

Privacy
Your notes stay on your device or in your personal browser sync. NotePin does not send your notes to external servers.

Homepage: https://nrnworld.one/p/notepin
Support: bynrnworld@gmail.com
```

## Svenska

### Kort beskrivning

Fäst anteckningar på valfri webbsida. Förankra i element, privat och offline.
```

### Detaljerad beskrivning

```
NotePin låter dig fästa flytande anteckningar direkt på vilken webbsida som helst — precis där du behöver dem.

Så skapar du en anteckning
På valfri sida: håll inne högerklick i 1 sekund. NotePin öppnar en meny så att du kan lägga till en anteckning utan att störa den vanliga högerklicksmenyn.

Det här får du
- Smarta anteckningar som hör till sidan där du skapade dem
- Dra för att flytta, ändra storlek i hörnet och klicka för att lyfta fram en anteckning
- Autosparning medan du skriver
- Översikt över sparade anteckningar — sök, öppna och hantera över flera sajter
- Exportera / importera JSON-backup
- Valfri webbläsarsynk när det finns; annars sparas allt lokalt
- Gränssnitt på svenska och engelska

Integritet
Dina anteckningar stannar på din enhet eller i din personliga synk. NotePin skickar inte dina anteckningar till externa servrar.

Hemsida: https://nrnworld.one/p/notepin
Support: bynrnworld@gmail.com
